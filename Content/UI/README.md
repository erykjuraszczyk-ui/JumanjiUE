# JUMANJI Mobile HUD

Create a Widget Blueprint named WBP_JumanjiHUD with parent class UserWidget.

Suggested first layout:
- left side: movement thumbstick/joystick;
- right side: camera drag region;
- lower right: Jump and Interact buttons;
- upper left: Health and Stamina;
- upper right: minimap placeholder;
- upper center: Living Board event title and objective.

The Interact button's OnPressed event should call TryInteract on the possessed AJumanjiCharacter.

The Jump button should call Jump on Pressed and StopJumping on Released.

For movement and camera look, use Enhanced Input with touch-capable input actions or a dedicated touch-input component. Do not emulate a mouse click for the movement joystick.

## Wire the widget into the game

1. Create BP_JumanjiPlayerController as a child of AJumanjiPlayerController.
2. Assign WBP_JumanjiHUD to HUDWidgetClass in Class Defaults.
3. Create BP_JumanjiGameMode as a child of AJumanjiGameMode.
4. Set the Player Controller Class to BP_JumanjiPlayerController.
5. Set the Default Pawn Class to BP_JumanjiCharacter.
6. Select BP_JumanjiGameMode in Project Settings → Maps & Modes.

The C++ PlayerController creates the widget only for the local player. The widget asset itself is authored in Unreal Editor and is not generated by the source repository.
