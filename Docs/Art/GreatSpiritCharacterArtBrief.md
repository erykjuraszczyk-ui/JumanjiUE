# Great Spirit — Character Art Brief

## Reference

Use the nine-panel image supplied by the project owner, titled GREAT SPIRIT JUMANJI, as the visual reference for this roster.

The reference has a dark jungle atmosphere, close-up fantasy portraits, glowing facial markings, ornate head pieces, leaves and feathers, and colored frames with Roman-numbered identities.

## Shared design language

- Fantasy ceremonial ornaments; do not copy real-world sacred symbols.
- Recognizable facial markings and a central forehead ornament.
- Feather, leaf, braid or carved-stone details.
- Strong readable head silhouettes.
- Expressive eyes and distinct facial shapes.
- Controlled emissive details.
- Consistent material quality, lighting and portrait framing.

Each character must remain recognizable at mobile-card size. Prioritize silhouette, dominant palette and face-marking motif over tiny surface detail.

## Production requirements

- Produce a clean front-facing portrait and a neutral full-body turnaround for each character.
- Keep all nine heads within a shared portrait frame and camera setup.
- Use one shared humanoid skeleton when compatible with the character proportions.
- Keep facial accessories and ornaments modular where practical.
- Create optimized mobile materials and texture sets.
- Include LODs and test portraits at their actual in-game card size.
- Store source files and exports with provenance and license notes.
